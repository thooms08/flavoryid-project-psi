# Panduan Kelola Menu — Flavory.id

## Cara Mengakses
Klik tab **"Opsi Lainnya"** di navbar kasir → pilih **"Kelola Menu"**.
Di HP, buka menu hamburger (☰) dulu.

> Maksimal jumlah menu yang dapat ditambahkan: **500 menu**.

---

## Langkah Menambah Menu

### 1. Isi Data Dasar (Wajib)
- **Nama Menu** — ketikkan nama makanan/minuman
- **Harga** — masukkan harga jual standar

### 2. Lengkapi Detail Menu (Opsional)
Klik **ikon grid (⊞)** di samping kolom harga untuk menambahkan:
- **Deskripsi** — penjelasan singkat tentang menu
- **Foto** — unggah gambar produk
- **Varian / Level** — tambahkan ukuran (Reguler, Large) atau level pedas, masing-masing bisa beda harga
- **Stok Menu** — atur jumlah stok tersedia

### 3. Atur Kategori & Tipe
- **Kategori** — kelompokkan menu (Makanan, Minuman, Snack, dll.). Jika kosong, otomatis masuk "F&B"
- **Tipe Menu** — tandai sebagai Best Seller 🔴, Menu Utama, atau Rekomendasi

### 4. Simpan
Klik tombol **Simpan** untuk menyimpan menu baru.

---

## Tambah Banyak Menu Sekaligus
Tekan tombol **"+"** pada form untuk menambah baris baru. Bisa input hingga **20 menu sekaligus** dalam satu kali simpan.

---

## Edit & Hapus Menu
- **Edit** — cari menu di daftar bawah, klik ikon **pensil (✏️)** untuk mengubah nama, harga, atau stok
- **Hapus** — klik ikon **tempat sampah (🗑️)** di samping tombol edit

---

## Tips
Gunakan nama menu yang singkat dan jelas agar mudah dicari kasir. Pastikan harga dan varian diisi akurat agar proses kasir berjalan tanpa kendala perhitungan.
