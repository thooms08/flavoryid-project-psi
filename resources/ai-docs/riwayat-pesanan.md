# Panduan Riwayat Pesanan & Cetak Struk — Flavory.id

## Cara Mengakses
Setelah konfirmasi pembayaran, otomatis diarahkan ke halaman **Riwayat Pesanan**. Halaman ini adalah pusat rekapitulasi harian transaksi outlet.

---

## Fitur Halaman Riwayat Pesanan
- **Daftar Pesanan (Cards)** — seluruh pesanan yang sudah dibayar tampil sebagai kartu rapi
- **Ringkasan Pendapatan** — Total Penjualan (jumlah struk) dan Total Pendapatan (Rp) secara real-time
- **Filter Tanggal** — saring data berdasarkan rentang harian, mingguan, atau bulanan
- **Pencarian Cepat** — cari pesanan via nama pelanggan atau nomor Order ID

---

## Cara Membuka Menu Struk
Klik **ikon titik tiga (⋮)** di pojok kanan atas setiap card pesanan → muncul dropdown pilihan metode struk.

---

## 5 Pilihan Metode Struk

### 1. Struk Digital (QR Code)
Sistem menampilkan QR Code besar di layar kasir. Pelanggan scan dengan kamera HP untuk melihat struk di HP mereka.
- ✅ Praktis, ramah lingkungan, tidak butuh printer

### 2. Struk Digital (WhatsApp)
Struk digital dikirim langsung ke WhatsApp pelanggan dalam bentuk pesan teks rapi.
- ✅ Paling praktis, pelanggan tidak perlu scan
- ⚠️ Syarat: nomor WhatsApp pelanggan harus sudah diisi saat input pesanan

### 3. Cetak Fisik (Bluetooth)
Cetak struk fisik via smartphone ke printer thermal 58mm.
- Butuh aplikasi "Printer Bluetooth Sederhana"
- Langkah: install aplikasi → aktifkan Bluetooth → pairing ke printer → cetak

### 4. Cetak Fisik (USB Printer)
Cetak via kabel USB ke printer thermal ESC/POS 58mm.
- ⚠️ Hanya untuk Laptop/PC, tidak bisa di HP/Tablet
- Langkah: colok kabel USB printer ke laptop → klik metode ini → cetak via dialog browser

### 5. Cetak Struk Dapur (Kitchen) via Bluetooth
Kirim rincian pesanan ke dapur. Butuh printer Bluetooth 58mm dan aplikasi Printer Bluetooth.
- Bisa juga diakses dari dashboard kasir sebelum pelanggan membayar

---

## Keamanan Data
Halaman Riwayat Pesanan **tidak memiliki fitur Hapus**. Ini disengaja untuk mencegah manipulasi data penjualan oleh kasir atau karyawan.
