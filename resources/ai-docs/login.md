# Panduan Log In — Flavory.id

## Langkah Login

1. **Akses halaman Log In** — klik tombol "Log In" di pojok kanan atas website. Di HP, buka menu hamburger (☰) lalu pilih "Log In".
2. **Masukkan Username dan Password** yang dibuat saat pendaftaran.
3. **Opsi "Ingat Saya"** — centang jika menggunakan perangkat pribadi agar tetap login beberapa hari tanpa input password ulang. Jangan centang di perangkat publik.
4. **Klik "Masuk Sekarang"** — sistem memverifikasi dan mengarahkan ke Dashboard Kasir.
