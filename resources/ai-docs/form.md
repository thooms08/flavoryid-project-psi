# Panduan Pengaturan Form Data Pesanan — Flavory.id

## Cara Mengakses
Klik tab **"Opsi Lainnya"** di navbar kasir → pilih **"Pengaturan Form"**.
Di HP, buka menu hamburger (☰) dulu.

---

## Pilihan Form yang Tersedia
Anda bisa mengaktifkan atau menonaktifkan field berikut sesuai kebutuhan outlet:

| Field | Keterangan |
|---|---|
| **Nama Pelanggan** | Kolom nama saat input pesanan |
| **Nomor Meja** | Nomor meja pelanggan |
| **No. WhatsApp** | Untuk kirim struk digital via WhatsApp |
| **Keterangan / Catatan Pelanggan** | Catatan khusus dari pelanggan |
| **Diskon Transaksi** | Kolom diskon per transaksi |
| **Bukti Pembayaran** | Kamera untuk foto bukti bayar QRIS/Transfer |
| **Voucher** | Kolom kode voucher |

---

## Cara Mengaktifkan / Menonaktifkan Form
Klik **toggle (sakelar)** pada masing-masing field:
- 🟠 **Oranye** = aktif, field muncul di halaman kasir saat buat pesanan
- ⚫ **Abu-abu** = nonaktif, field tidak muncul

---

## Tips
Aktifkan **hanya form yang benar-benar dibutuhkan**. Form terlalu banyak memperlambat proses input pesanan. Form yang efektif membuat kasir lebih cepat melayani pelanggan.
